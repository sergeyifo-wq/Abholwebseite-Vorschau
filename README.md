# Abholportal · öffentliche Demo

[Demo öffnen](https://sergeyifo-wq.github.io/Abholwebseite-Vorschau/)

Klickbarer Prototyp des geplanten Abholportals mit ausschließlich fiktiven Beispieldaten. Die Demo zeigt den vorgesehenen Ablauf auf Basis von Power Pages, Dataverse und Power Automate:

- **Öffentliche Website:** Startseite, simulierte Anmeldung per E-Mail-Code inklusive Einlösen einer Einladung, Formular „Zugang anfragen“.
- **Partnerportal:** Übersicht mit Wochenplanung, Abholbedarf melden in vier Schritten, eigene Meldungen mit Statusverlauf, empfangene E-Mails.
- **Interne App (Ausblick):** Dashboard, Abholmeldungen mit Excel-Export, Wochenplanung, Übergabestellen, Partnerzugänge, Zugangsanfragen, Versandprotokoll.
- **Demo-Postfach:** alle E-Mails, die das System versenden würde – es wird nichts versendet.

Direktlinks, z. B. `#/partner/wien/melden` oder `#/intern/meldungen`.

Keine echte Anmeldung, keine Datenbankanbindung, keine Übermittlung an Interzero und kein E-Mail-Versand. Bitte keine echten Daten eingeben. Die Ansichtsumschaltung zeigt den vorgesehenen Ablauf und stellt keine Zugriffssicherheit dar. Änderungen bestehen nur bis zum Neuladen. Alle enthaltenen Beispieldaten sind öffentlich. Dies ist keine offizielle Interzero-Website.

Dieses Repository enthält nur die statischen Demo-Dateien. Der vollständige Quellcode und die Microsoft-Implementierung bleiben im privaten Repository. Schrift: Libre Franklin (SIL Open Font License), lokal eingebunden.
