# Abholportal · öffentliche Vorschau

[Website öffnen](https://sergeyifo-wq.github.io/Abholwebseite-Vorschau/)

Interaktive Vorschau mit ausschließlich fiktiven Beispieldaten. Die Demo zeigt die Startseite, Administration und Partneransichten für Wien und Graz. Abholmeldungen und neue Übergabestellen lassen sich ausprobieren; Änderungen bestehen nur bis zum Neuladen.

Keine echte Anmeldung, keine Datenbankanbindung, keine Übermittlung an Interzero und kein E-Mail-Versand. Bitte keine echten Daten eingeben. Die Ansichtsumschaltung zeigt den vorgesehenen Ablauf und stellt keine Zugriffssicherheit dar. Alle enthaltenen Beispieldaten sind öffentlich.

Dieses Repository enthält nur die statischen Vorschau-Dateien. Der vollständige Quellcode und die Microsoft-Implementierung bleiben im privaten Repository. Der produktive Betrieb benötigt Power Pages, Dataverse und die durch IT konfigurierte Microsoft-Anmeldung.
